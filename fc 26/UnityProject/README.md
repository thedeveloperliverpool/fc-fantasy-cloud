# FC 26 Unity (2023.2)

This folder is a Unity 2023.2 project shell.

## Create/Open
1. Open Unity Hub
2. Add project > select `fc 26/UnityProject`
3. If Hub warns it is not a valid project, create a new Unity 2023.2 project in `fc 26/UnityProject` and keep this folder.
