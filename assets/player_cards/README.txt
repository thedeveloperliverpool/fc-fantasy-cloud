Approved player portrait files go here.

Naming format:
- lowercase
- spaces replaced with underscores
- punctuation removed

Examples:
- cristiano_ronaldo.png
- lionel_messi.png
- kylian_mbappe.png

Supported formats:
- .png
- .jpg
- .jpeg
- .webp

If no portrait file exists for a player, the card front uses the built-in silhouette fallback.
